# Бэкапы

Ветка `backup` хранит снимки приложения: код на момент бэкапа и зашифрованную копию базы.
Каждый бэкап — отдельный коммит, в его описании перечислено, что изменилось с прошлого.

| Файл | Что внутри |
|---|---|
| `backup-ГГГГ-ММ-ДД.tar.gz.gpg` | Копия базы Supabase из workflow `Backup`: `roles.sql`, `schema.sql`, `data.sql` |

Репозиторий публичный, поэтому база лежит только в зашифрованном виде (GPG, AES-256).
Пароль — секрет `BACKUP_PASSPHRASE`, его копия должна быть в менеджере паролей.

Расшифровать:

```bash
gpg -o backup.tar.gz --decrypt backups/backup-2026-11-04.tar.gz.gpg
tar -xzf backup.tar.gz
```

Как восстановить базу из этих файлов — в разделе «Бэкапы» основного [README](../README.md).
